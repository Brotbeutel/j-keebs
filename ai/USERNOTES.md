    - Keyboard Layout Editor NG (https://editor.keyboard-tools.xyz/)

      - eine benutzerfreundlichere Version des KLEs mit mehr Features

    - Plate & Case Builder (http://builder.swillkb.com/)

      Generiere Switch Plates aus KLE-JSONs

    - qmk2via (https://github.com/misterkeebs/qmk2via)

      - konvertiert QMK-Firmware zu JSON-Dateien, die mit dem KLE bearbeitet werden können

    - QMK Toolbox (https://qmk.fm/toolbox)

      - Tool zum Flashen von Tastatur-Firmware

    - QMK Configurator (https://config.qmk.fm/)

      - Erstelle und bearbeite Firmware-Dateien

    - Keyboard Layout Editor (https://www.keyboard-layout-editor.com/)

      - erstelle Keyboard Layouts und Exportiere JSON-Dateien

    - Fat Plate Generator (https://github.com/Brotbeutel/Fat-Plate-Generator)

      - generiere 'Fat-Plates' zum Drucken

    - Plates'n'Cases (https://github.com/Brotbeutel/Plates-n-Cases)

      - von mir erstellte Switch Plates und Tastaturgehäuse

    - Keybr.com - Tippen üben (https://www.keybr.com/)

      - Die beste App zum Tippen lernen und üben, die ich kenne!
